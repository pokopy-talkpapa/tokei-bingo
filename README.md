# たねまき とけいビンゴ（なんじ）

対話型算数スクール **たねまき** 🌱わくわくコース（1年生）の授業用ツール。
**みじかいはり（短針）だけを見て「いま なんじ？」を読む**練習を、ルーレット＋ビンゴで楽しく。

## つかいかた
1. **まわす** … 短針がぐるぐる回る
2. **ストップ** … 好きなところで止める
3. **こたえ** … 「○じ」をひらがなで表示＋りれきに記録
4. **つぎ** … 次のルーレットへ

「でた じこく（りれき）」に貯まった○じを、手元の紙ビンゴカードでマークして遊べます。

## おたすけ（出し入れトグル）
- **ながいはり** … 長針を出す／消す（初期オフ＝短針だけ）
- **○じゾーン** … 短針の先のドーナツリング。どのゾーンにいるかで「なんじ」が読める（初期オン）
- **すうじ** … 文字盤の数字（難度上げで消せる）

## ねらい
短針が2つの数字の間にあるとき、**手前（小さい方）の数字**を読む。
例：7と8の間ならどこでも「7じ」。12と1の間なら「12じ」。
